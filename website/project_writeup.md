# Your Personal Finance Tracker and Planner

## Overview
This website are build to facilitate mainly mobile user to:
- Profiled their finance profile, revenue, assets, consumption, and their personal appetite.
- Input their expenses and income 
- Track their expenses and inco me
- Plan their budget

## Components/Feature
- A authentication system through email.
- User profile and username
- Click-through to a telegram-bot
- A  pie chart, wave line chart as a dashboard (powered by ApexCharts)
- A dashboard with user-profile, salary, assets, all able to edit through chart or directly through the dashboard.
- A scrollable card of expenses and income, enable photos viewing if a photos is included.
- Ability to delete the card and deleting the db record.
- Ability to filter expenses and income by date, category, and amount for the dashboard and card view. 
- button to do data-strengthening over user's email (syncing database with bank-forwarded record)

## Tech Stack
- *tanstack* for database and caching
- *better-auth* for authentication
- lazy-loading with *vue* and *tanstack*
- *shadcn* for components
- *vue* for frontend framework
- *mongodb* no sql for database
- A *django* backend for the API.
